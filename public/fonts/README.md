# Schrift für den Schriftzug „Heartfelt Futures“ (Kopfzeile)

**Cosmic Octo** von Hanken Design Co. – kommerzielle Schrift.
Kauf: https://hanken.gumroad.com/l/CosmicOcto oder MyFonts. Wichtig: eine Lizenz,
die die Einbindung auf einer Website erlaubt (Webfont / Web-Embedding).

Datei hier ablegen, genau so benannt:

- `CosmicOcto-Regular.woff2` (bevorzugt)
- optional zusätzlich `CosmicOcto-Regular.woff`

Liegt nur eine `.otf`/`.ttf` vor, kann sie in WOFF2 umgewandelt werden – sofern die
Lizenz das erlaubt. Ein anderer Schnitt (z. B. Bold) ist möglich: dann Dateinamen und
`font-weight` in `src/styles/global.css` (`@font-face` „Cosmic Octo“) anpassen.

Solange die Datei fehlt, erscheint der Schriftzug in Inter.
