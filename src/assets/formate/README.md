# Collagen für die Formate

Hier die Collagen ablegen – sie erscheinen dann automatisch im Abschnitt „Formate“.
Bis eine Datei vorliegt, zeigt die Seite einen Platzhalter.

- Format: Hochformat **4:5**, mindestens **1080 × 1350 px** (JPG, PNG oder WebP)
- Dateinamen (müssen genau so heißen, wie in `src/data/formate.ts` → `bild` eingetragen):

| Format | Dateiname |
|---|---|
| Inventing the Future | `inventing-the-future.jpg` |
| Exploring Alternative Futures | `exploring-alternative-futures.jpg` |
| Speculative Design | `speculative-design.jpg` |
| Verliebt in die Zukunft | `verliebt-in-die-zukunft.jpg` |
| Placemaking | `placemaking.jpg` |
| Learning Journeys | `learning-journeys.jpg` |

Andere Endung (z. B. `.png`)? Dann den Dateinamen in `src/data/formate.ts` anpassen.
